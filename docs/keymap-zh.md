# ESP32-SI4732 收音机 · 按键操作表（中文定制版）

## 一、手势定义

| 手势 | 判定条件 |
|---|---|
| 单击 | 按下后 0.5 秒内松开 |
| 中按 | 按住 0.5 ~ 2 秒后松开 |
| 长按 | 按住超过 2 秒（按住期间只触发一次） |
| 双击 | 两次单击的间隔小于 0.4 秒 |
| 左转 / 右转 | 旋转编码器，不按 |
| 按住转 | 按住旋钮的同时旋转 |

---

## 二、主界面（无菜单、无模式）

| 操作 | 功能 |
|---|---|
| 左转 / 右转 | **步进模式**：按当前步长调频率（如 100K）<br>**搜索模式**：跳到上一个 / 下一个台 |
| 单击 | 打开音量调节 |
| 中按 | **切换 步进模式 ⇄ 搜索模式**（信息栏第三行同步显示）|
| 长按 | 无动作（已在主界面，退无可退） |
| **双击** | 打开主菜单  |
| **按住 + 转** | 进入频率逐位输入，先选位 |

---

## 三、音量模式

| 操作 | 功能 |
|---|---|
| 转 | 调音量 0 ~ 63 |
| 单击 | 退出音量，回主界面 |
| 中按 | 静音开 / 关（切换）（推荐，立即生效） |

---

## 四、主菜单

| 操作 | 功能 |
|---|---|
| 转 | 上下切换菜单项（一屏 5 项，循环） |
| 单击 | 进入选中项 |
| 中按 | 也进入选中项（例外见下） |
| 长按 | **退出菜单，回主界面** |

> 例外：「VFO」这一项 —— 单击 = 把当前频率**复制**到另一个槽；中按 = **切换 A/B**。

---

## 五、子页面（步进 / 带宽 / 模式 / 增益 / 补偿 / 静噪 等）

| 操作 | 功能 |
|---|---|
| 转 | 调整参数值 |
| 单击 | 确认 |
| 长按 | 退出子页面，回主界面 |

---

## 六、频率逐位输入（主界面按住旋钮再转进入）

| 操作 | 功能 |
|---|---|
| 转 | 改当前选中位的数字 |
| 按住 + 转 | 换位（个 / 十 / 百 / 千…） |
| 单击 | 确认（把频率对齐到当前输入步长） |
| 长按 | 退出输入，回主界面 |

---

## 七、搜索模式（中按进入后）

| 操作 | 功能 |
|---|---|
| 转 | **跳到上一个 / 下一个电台**（SI4732 芯片原生 seek） |
| 单击 | 打开音量 |
| 双击 | 退回步进模式 |
| 长按 | 无动作 |

> 扫台过程中会自动静音（原厂设计，避免噪音），收到台后自动恢复。

---

## 八、其它状态

| 状态 | 操作 |
|---|---|
| 屏幕自动熄灭后 | 按任意键 / 转旋钮 → 唤醒 |
| 录音 / 扫描等长任务进行中 | 转旋钮 → 中止 |

---

## 九、没有的功能（别试了）

| 操作 | 结果 |
|---|---|
| 连按三次 | 没有专门功能。第三次会被当成新的一次单击，结果是打开音量 |
| 长按当作"确认" | 长按已统一为**后退**，不再有确认语义 |
| 手动熄屏 | 已取消，由「设置 → 睡眠定时」自动熄屏（默认 30 秒） |

# 实现备注（固件 v2，2026-11-04 21:00 烧录）

## 已按本表实现

| 表格条目 | 实现位置 |
|---|---|
| 主界面 中按 = 切步进/搜索 | `ats-mini.ino` loop() 的 `wasShortPressed` 分支 |
| 主界面 双击 = 主菜单 | loop() 的 `wasClicked` 双击分支 |
| 音量模式 单击 = 退出 | `Menu.cpp` 的 `clickVolume()` |
| 音量模式 长按 = 静音 | loop() 长按分支内的 `CMD_VOLUME` 分派 |
| 搜索模式 双击 = 退回步进 | 双击分支内的 `seekRotate` 判断 |

## 已知副作用（非缺陷）

1. **双击开菜单会先闪一下音量条**（约 100~200ms）
   因为第一击必然先按"单击"处理。除非给单击加 0.3 秒延迟。

2. **音量模式静音需按住满 2 秒**
   按住 1.9 秒松手会被判为中按 → 退出音量。

3. **子页面"单击=确认"等价于"退出"**
   本固件子页面参数转动即生效，没有暂存/回滚机制。

4. **搜索模式下中按** = 退回步进（与双击等效）
   表格未定义，按"中按=切模式"的全局规则补齐。

5. **主菜单单击与中按都是"进入"**
   退出只能长按。
